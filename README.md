## 🧩 Depth-First Search Maze Solver  
Welcome to the DFS Maze Solver! This Java program utilizes a user-made maze and navigates a green square to the end, all using a Depth-First Search algorithm. No input is needed after that — just sit back and let the magic unfold! 🟢

## 🚀 Features:  
Maze Generation: Takes a text file maze filled with walls and pathways and solves it!  
Autonomous Solving: The green square explores every path until it finds the exit.  
Efficient Algorithm: Powered by Depth-First Search, ensuring a complete solution every time.
